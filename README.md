# 🌱 Om Sai Dalimb Nursery Website

A responsive, mobile-friendly website developed for **Om Sai Dalimb Nursery**, located near Shirdi, Maharashtra, India. The website helps customers explore pomegranate plant varieties, view nursery images, find contact information, and send enquiries directly through WhatsApp.

## 📌 About the Project

Om Sai Dalimb Nursery specializes in pomegranate plants and provides a convenient way for customers to enquire about plant varieties, current availability, pricing, and wholesale orders.

This website is designed with a mobile-first approach to provide a smooth browsing experience on smartphones, tablets, and desktop computers.

## ✨ Features

* **Responsive Design:** Works on mobile phones, tablets, and desktops.
* **Home Page:** Introduces the nursery and its offerings.
* **Plant Varieties:** Displays Bhagwa, Super Bhagwa, and Shard King pomegranate varieties.
* **Image Gallery:** Showcases nursery and plant photographs.
* **About Us:** Provides information about the nursery.
* **Contact Information:** Displays phone numbers, email, and location.
* **WhatsApp Integration:** Allows customers to contact the nursery directly.
* **Enquiry Form:** Collects customer details and prepares an enquiry message in WhatsApp.
* **Google Maps Integration:** Helps visitors find the nursery's location.
* **Mobile Navigation:** Makes it easier for mobile users to browse the website.

## 🛠️ Technologies Used

* **HTML5** — Website structure and content.
* **CSS3** — Styling, layouts, and responsive design.
* **JavaScript** — Interactive elements and enquiry form functionality.
* **Bootstrap** — Responsive design components, where used.

## 🚀 Website Deployment

The website can be hosted for free using GitHub Pages.

### Deployment Steps

1. Upload the website files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** under *Code and automation*.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish the website.
8. Copy the published URL from the Pages settings and share it with visitors.

For more information, refer to the [GitHub Pages documentation](https://docs.github.com/en/pages).

## 🔧 Local Setup

To run the website on your computer:

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Browse the pages and test the navigation, images, and contact links.

No backend server or database is required for the current static website.
